## ✍️ 写作约定

1. **一个讲义小节 = 一个 md 文件**，命名如 `F3-数字逻辑电路基础.md`
2. **橙色作业**用 `templates/作业模板.md` 的格式写在对应小节文件里
3. **电路图**用 Logisim / draw.io 画好后截图，存进该阶段的 `images/`，用相对路径引用
4. **一节内容 + 对应作业 = 一次 commit**，如 `F3: 完成或非门作业分析`
5. 完成一个章节后回来更新上面的进度表
